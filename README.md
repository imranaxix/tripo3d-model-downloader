# Tripo3D Free Model Downloader

A lightweight userscript that intercepts network requests on [Tripo Studio](https://studio.tripo3d.ai/) to download fully textured 3D models (`.fbx` / `.glb`).

## How to Install

1. Install the **Tampermonkey** extension for your browser (Chrome, Edge, Firefox).
2. Enable **Allow User Scripts** or **Developer Mode** in Tampermonkey settings if prompted.
3. Open Tampermonkey, click **Create a new script**, and paste the code from [`tripo-downloader.user.js`](./tripo-downloader.user.js).
4. Save the script (`Ctrl + S`).
5. Open any model on **Tripo Studio**, wait for it to load, and click **Download Model**.
